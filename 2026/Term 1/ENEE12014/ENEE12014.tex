	Node: A point in a circuit which two or more elements join.\\
	Essential Node: Where three or more elements join.\\
	Path: A trace of adjoining basic elements with no repition.\\
	Branch: A path connecting two nodes.\\

	Mesh: A loop that does not enclose another loop.
	\subsection{Nodal Analysis:}
	Nodal analysis is known as the node-voltage method. This is a method calculating node voltages in a planar circuit. It utilizes the fundamentals of KCL and Ohm's Law.
	\subsubsection{Procedure}
	\begin{enumerate}
		\item Identify each essential node.
		\item Pick and label a reference node (usually ground), then label the node voltages at the remaining essential nodes.
		\item Write KCL equations for each non-reference essential node.
		\item Solve equations.
		\item Find voltages, power and current at each node.
	\end{enumerate}

	\section{Mesh Analysis}
	\subsection{Branch Current Analysis:}
	\begin{enumerate}
		\item Assign a distinct current of arbitrary direction to each direction.
		\item Polarities of circuit elements are determined by assumed current direction.
		\item Apply KVL around each loop.
		\item Apply KCL at each essential node.
		\item Solve for current values.
	\end{enumerate}
	\subsection{Mesh Analysis:}
	Extension of the above method. It defines currents in such a way that there is no need to apply KCL.
	\begin{itemize}
		\item Define currents for each mush of the networks.
		\item Branch current is now expressed in terms of unique mesh currents.
	\end{itemize}
	\subsubsection{Procedure}
	\begin{enumerate}
		\item Assign distinct current to each mesh. The easiest way is have them all going in the same direction.
		\item Indictate polarities through the loop with respect to current direction.
		\item Apply KVL on each mesh.
		\item Solve for currents.
	\end{enumerate}

	\section{RC Circuits}
	\subsection{Capacitors:}
	Constructed using a dialectric material middle, sandwhiched between two conducting plates. As it charges an electric field is generated. As such its true characteristics are shown when a change in voltage or current take places. To a DC source there is zero change in current because capacitors act an O/C.
	$$i=C\frac{dv}{dt}$$
	Voltage cannot change instantaneously as it results in infinite induced current. It takes time for voltage to reach desired voltage and vice versa to reach 0V.
	\begin{align*}
		i=&C\frac{dv}{dt}\\
		idt=&Cdv\\
		dv=&\frac{1}{C}idt\\
		\int^{v(t)}_{v(t_{0})}1dx=&\frac{1}{C}\int^{t}_{t_{0}}idx\\
		v(t)-v(t_{0})=&\frac{1}{C}\int^{t}_{t_{0}}idx\\
		v(t)=&\frac{1}{C}\int^{t}_{t_{0}}idx+v(t_{0})
	\end{align*}
	\begin{align*}
		p=&vi\\
		=&vC\frac{dv}{dt}\\
		=&i[\frac{1}{C}\int^{t}_{t_{0}}idx+v(t_{0})]\\
		W=&\frac{Cv^{2}}{2}
	\end{align*}
	Power is in Watts and Energy (W) is in Joules.
	\subsection{Equivalent Capacitence:}
	\subsubsection{Series}
	$$C_{eq}=\frac{1}{\sum^{k}_{n=1}\frac{1}{C_{n}}}$$
	$$v(t_{0})=v_{1}(t_{0})+v_{2}(t_{0})+...+v_{n}(t_{0})$$
	\subsubsection{Parallel}
	$$C_{eq}=\sum^{k}_{n=1}C_{n}$$
	\subsection{Inductors:}
	Inductors can be thought of as the dual to the capacitor. Similar to the capacitor, inductors only exhibit true behaviour on current and voltage changes. Inductors are created by wrapping wire material around a ferromagnetic core. As such they are designed to generate magnetic field linking the unit. Inductors need a change in current to induce voltage. A constant current (DC) would induce OV.
	\begin{align*}
		v=&L\frac{di}{dt}\\
		vdt=&Ldi\\
		L\int^{i(t)}_{i(t_{0})}1dx=&\int^{t}_{t_{0}}vdy\\
		i(t)-i(t_{0})=&\frac{1}{L}\int^{t}_{t_{0}}vdy\\
		i(t)=&\frac{1}{L}\int^{t}_{t_{0}}vdy+i(t_{0})
	\end{align*}
	\begin{align*}
		p=&vi\\
		=&iL\frac{di}{dt}\\
		=&v[\frac{1}{L}\int^{t}_{t_{0}}vdy+i(t_{0})]\\
		w=&\frac{Li^{2}}{2}
	\end{align*}

	KVL around ABCDA
	\begin{align*}
		v_{R}+v_{L}=&v_{S}\\
		iR+L\frac{dv}{dt}=&v_{S}\\
		\frac{di}{dt}+\frac{iR}{L}=&\frac{v_{S}}{L}\\
		i(t)=&\frac{\int e^{\int\frac{R}{L}dt}(\frac{v_{S}}{L})dt+K}{e^{\int\frac{R}{L}dt}}\\
		=&\frac{v_{S}}{R}+Ke^{-\frac{t}{\tau_{L}}}
	\end{align*}
	Assuming @ $t=0$, $i=I_{0}$, that when the switch closes there is some energy already in the inductor.
	\begin{align*}
		K=&I_{0}-\frac{I_{S}}{R}\\
		\therefore i(t)=&\frac{v_{S}}{R}+(I_{0}-\frac{v_{S}}{R})e^{-\frac{t}{\tau_{L}}}
	\end{align*}
	\subsection{Summary:}
	If at $t=0$, $I_{0}=0$ then:
	$$i(t)=\frac{v_{S}}{R}(1-e^{-\frac{t}{\tau_{L}}})$$
	$$v_{L}(t)=v_{S}e^{-\frac{t}{\tau_{L}}},\;\tau_{L}=\frac{L}{R}$$
	$$v_{R}=V_{S}-v_{L}$$
