		\item $\rho$: Resistivity ($(\Omega\cdot m)^{-1}$)

	\subsection{Essential Points:}
	Node: A point in a circuit which two or more elements join.\\
	Essential Node: Where three or more elements join.\\
	Path: A trace of adjoining basic elements with no repition.\\
	Branch: A path connecting two nodes.\\
	Essential Branch: A path connecting two essential nodes.\\
	Loop: First and last node are the same node.\\
	Mesh: A loop that does not enclose another loop.
	\subsection{Nodal Analysis:}
	Nodal analysis is known as the node-voltage method. This is a method calculating node voltages in a planar circuit. It utilizes the fundamentals of KCL and Ohm's Law.
	\subsubsection{Procedure}
	\begin{enumerate}
		\item Identify each essential node.
		\item Pick and label a reference node (usually ground), then label the node voltages at the remaining essential nodes.
		\item Write KCL equations for each non-reference essential node.
		\item Solve equations.
		\item Find voltages, power and current at each node.
	\end{enumerate}

	\section{Mesh Analysis}
	\subsection{Branch Current Analysis:}
	\begin{enumerate}
		\item Assign a distinct current of arbitrary direction to each direction.
		\item Polarities of circuit elements are determined by assumed current direction.
		\item Apply KVL around each loop.
		\item Apply KCL at each essential node.
		\item Solve for current values.
	\end{enumerate}
	\subsection{Mesh Analysis:}
	Extension of the above method. It defines currents in such a way that there is no need to apply KCL.
	\begin{itemize}
		\item Define currents for each mush of the networks.
		\item Branch current is now expressed in terms of unique mesh currents.
	\end{itemize}
	\subsubsection{Procedure}
	\begin{enumerate}
		\item Assign distinct current to each mesh. The easiest way is have them all going in the same direction.
		\item Indictate polarities through the loop with respect to current direction.
		\item Apply KVL on each mesh.
		\item Solve for currents.
	\end{enumerate}

	\subsubsection{Norton Circuits}
	Usualy a Norton equivalent circuit is easier too calculate the S/C current then O/C voltage. However most of the time it is easier to convert from the Th\'evenin circuit.
	\subsection{Th\'evenin Equivalent Resistance:}
	Only works with independent sources. The short cut method:
	\begin{itemize}
		\item Deactivate all power sources
			\begin{itemize}
				\item Ideal voltage sources become S/C
				\item Ideal current sources become O/C
				\item Internal resistance sources are included in circuit
			\end{itemize}
		\item Resistance is calculated from the reference terminals
	\end{itemize}
	\subsection{Maximum Power Transfer:}
	Important parameters describing the power transfer from source too load. It tells us 2 main things:
	\begin{enumerate}
		\item Amount of power transferred
		\item Efficiency
	\end{enumerate}
	\begin{center}
	\begin{tikzpicture}[thick, font=\Large, scale=0.75, transform shape]
	    % Voltage Source
	    \draw (0,0) to[V, invert, l=$V_{TH}$] (0,4);
	    % Top branch with Thevenin Resistor
	    \draw (0,4) to[R, l_=$R_{TH}$] (4,4);
	    % Nodes A and B with Load Resistor
	    \draw (4,4) node[ocirc, label=above right:A] {}
		  to[R, l=$R_L$] (4,0) 
		  node[ocirc, label=below right:B] {};
	    % Bottom branch connecting back to source
	    \draw (4,0) -- (0,0);

	    \draw[-stealth, thick] (5, 2.8) -- (5, 1.2) node[midway, right] {$I_L$};
	\end{tikzpicture}

	$$P_{L}=(\frac{V_{TH}}{R_{TH}+R_{L}})^{2}\times R_{L}$$
	Max Power are $R_{TH}=R_{L}$
	$$\therefore\;\;P_{L_{max}}=\frac{V_{TH}^{2}}{4R_{TH}}$$
	$$\text{Eff}=\frac{P_{L}}{P_{S}}=\frac{R_{L}}{R_{TH}R_{L}}$$
	\subsection{Superposition Theorem:}
	Linear circuit systems observe the principal of superposition. That is the total system response is the sum of all individual responses.\\[1\baselineskip]
	Voltage sources are S/C\\
	Current sources are O/C\\[1\baselineskip]
	Utilized to analyse circuits with both DC \& AC components.
